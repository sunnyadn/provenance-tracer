# Run parameters
- `cohort.json`: the 170 names traced in the five rounds (168 unique), private individuals masked.
- `cases.json`: for each case page, the entity, date range, record count, scope and the `provtrace trace` command that regenerates its input and report.

The raw records are not included: the AI Village dataset is gated. With access, `provtrace trace ...` rebuilds a case.
